# 腕上天文台 Android 天体模型库 v1

本目录只保存可按需下载的天体纹理和校验目录，与应用安装包独立。

应用内置太阳、水星、金星、地球、火星、木星、土星、天王星、海王星、冥王星、月球、银河系、黑洞。12 个卫星细节模型从本库单独下载，离线保存后可在天体阅览中打开。

`catalog.json` 记录每个 ZIP 和内部文件的 SHA-256、长度及图像来源。文件是既有腕上天文台使用的科学纹理；完整素材说明保留在应用中。土卫七的共享不规则网格仍随应用提供。

下载地址固定在 `model-library-v1` 标签下。后续资源修订使用新标签，不覆盖这批文件。此分支与标签不会修改应用更新的 latest.json 或 Latest Release。
